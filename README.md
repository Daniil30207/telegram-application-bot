
# Telegram-бот для приёма заявок

## О проекте

Telegram-бот для приёма и обработки заявок пользователей.
Проект создан на Python с использованием библиотеки aiogram.

## Возможности

- Меню пользователя и администратора.
- Просмотр услуг и цен.
- Пошаговое заполнение заявки.
- Проверка введённых данных.
- Сохранение заявок в базе данных SQLite.
- Уведомления администратора о новых заявках.
- Просмотр заявок и статистики.
- Изменение статусов заявок.
- Отмена заполнения заявки.

## Технологии

- Python
- aiogram
- SQLite
- python-dotenv

## Безопасность

Токен бота и другие секретные настройки хранятся в файле `.env`.
Не публикуйте этот файл в открытом репозитории.
